# Realizations

## How to Learn
- Study basics
- Learn by building and practicing

## How to Study
- **Use all of your indriyas (senses/faculties)**
  - Hand — write / code
  - Mouth — speak
  - Ear — listen
  - Eyes — see
  - Nose — good dhoop
  - Ahankar, Manas, Buddhi, Chitta
  - Active body
- Background music
- Set a learning objective with a timeframe
- Keep realisation of Purusha and Prakriti — know that Purusha is watching Prakriti's karmas. If there is any thought unrelated to the learning objective, either write it down or understand it's Manas playing its trick, and ignore it.
